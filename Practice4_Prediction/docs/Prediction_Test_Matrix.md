# Матрица тестирования

Условия: Host и Client на одном ПК (Multiplayer Play Mode или Development Build). Профиль сети
включается **на клиенте** клавишами F1–F3, метрики берутся из HUD клиента и журнала событий
(файл `prac4_log_*.txt`, путь показан в HUD).

| Тест | Сетевые условия | Действие | Ожидаемый результат | Фактический результат | Артефакт |
|---|---|---|---|---|---|
| T1 | Без эмуляции (F1) | Движение (WASD) обоих игроков | Плавное перемещение и репликация, коррекций нет | _RTT ≈ ___ мс; коррекций: ___; персонажи видят друг друга_ | _скриншот_ |
| T2 | 100 мс, 0% loss (F2) | Рывок **без** CSP (клавиша 1 → ВЫКЛ) | Видимая задержка до подтверждения | _«нажатие → рывок» = ___ мс; RTT ≈ ___ мс_ | [`media/baseline_no_prediction.*`](media/) |
| T3 | 100 мс, 0% loss (F2) | Рывок **с** CSP (клавиша 1 → ВКЛ) | Немедленный отклик, сервер сохраняет авторитетность | _«нажатие → рывок» = ___ мс; коррекций при обычной игре: ____ | [`media/prediction_enabled.*`](media/) |
| T4 | 175±25 мс, 4% loss (F3) | Движение и рывок | Система не принимает недопустимое состояние; возможны коррекции | _коррекций за 30 с: ___; потеряно вводов (сервер): ___; разрывов связи: нет_ | _скриншот_ |
| T5 | 175±25 мс, 4% loss (F3) | Намеренное расхождение: C (рывок в кулдаун) / X (ускорение) | Клиент получает авторитетную коррекцию | _отказов сервера: ___; последняя коррекция: ___ м; клиент вернулся к синему диску_ | [`media/correction_example.*`](media/) |

## Порядок проведения

1. Открыть сцену `Assets/Prac4/Scenes/Prac4_Prediction.unity`, запустить Play с двумя игроками.
2. Окно 1: **Запустить Listen Server (Host)**. Окно 2: **Подключиться как Client**.
3. В окне клиента нажать **R** (сброс статистики), выбрать профиль F1/F2/F3, выполнить действие.
4. Записать значения из HUD в столбец «Фактический результат», сохранить скриншот или видео в `docs/media/`.
